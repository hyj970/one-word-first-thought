## The word

**PETRICHOR** — the smell of rain on dry earth.

Why this word: it names a sensation everyone knows instantly but almost nobody can name. That gap — universal feeling, rare word — is exactly what wins a pairwise judge on surprise, vividness, and wit: it is specific (one precise smell, not a vague mood), sensory (you can almost smell it reading it), and it carries a quiet double meaning, the earth drinking the rain after a long dry spell. Against ordinary words it stands out; against other rare words it still wins on feeling chosen rather than generic, because everyone has lived it.

## How to run

```bash
python3 main.py
```

The program writes `PETRICHOR` plus a trailing newline to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Python 3.13, no network, no dependencies, deterministic — the same bytes every run.
